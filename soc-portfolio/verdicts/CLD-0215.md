# CLD-0215: Ransomware-pattern filename on file share: READ_ME_RESTORE.txt

Engagement: Cloudora · Shift 4 · 2026-08-29
Verdict: False positive · Severity (my rating): Informational (reported High)
QA review: Excellent

## Alert
Rule Ransom note filename pattern fired after READ_ME_RESTORE.txt was created by tara.kemp@cloudora.io in the HR-Training share at 09:10 UTC. The file was 1.2 KB of plain text, with no encryption activity, file modification storm, or related process alerts.

## Hypothesis
Malicious: The file was created as part of actual ransomware activity.
Benign: The file was intentionally created as part of the approved October security awareness exercise.

## Evidence checked
AV logs

At 09:10:44 UTC, LDN-SRV-FS1 recorded creation of \\HR-Training\READ_ME_RESTORE.txt by tara.kemp.
File size was 1.2 KB.
One second later, Defender triggered RansomNoteFilenamePattern.
AV specifically recorded no-encryption-activity=TRUE.
No file modification storm or related malicious process activity was identified.

Sign-in review

KQL searches were performed for tara.kemp@cloudora.io.
No Tara sign-in records were available in the signin table, so authentication telemetry could not independently establish her account baseline.

Helpdesk verification

HD-5150 documents the October security awareness exercise.
Tara Kemp is associated with the exercise.
The exercise includes an approved simulated ransom-note file and EICAR test placement.
The exercise was approved by the vCISO.
The alert's user and artifact type therefore match the documented awareness activity.

## Action
Close the alert as legitimate security-awareness activity under HD-5150. No containment or remediation is required. Continue monitoring normally and retain the helpdesk reference for future alerts generated by the approved exercise.

## Justification
Raw AV evidence confirms that Tara created the 1.2 KB READ_ME_RESTORE.txt file and that the ransomware-pattern rule fired immediately afterward. However, there was no encryption activity, file modification storm, or associated malicious process activity.

The event was verified against HD-5150, which documents a vCISO-approved October security awareness exercise involving a simulated ransom-note file. This provides a legitimate explanation that matches the user and artifact type observed in the raw evidence.

KQL searches for Tara returned no sign-in records, so authentication telemetry could not provide additional verification. However, the raw AV evidence and helpdesk documentation are consistent with the approved exercise, with no evidence supporting actual ransomware activity.

Therefore, the underlying activity is benign and the appropriate verdict is False Positive with Informational severity.

## Tuning note
Consider narrowly suppressing or tagging the ransom-note filename alert when the artifact is created as part of the specifically approved HD-5150 awareness exercise. Do not broadly suppress READ_ME_RESTORE.txt or ransom-note filename detections, since the same pattern outside the approved exercise could represent real ransomware activity.
