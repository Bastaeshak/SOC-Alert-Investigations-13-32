# CLD-0224: Weekly AV digest: 3 remediated detections, 0 active

Engagement: Cloudora · Shift 6 · 2026-08-31
Verdict: True positive · Severity (my rating): Low (reported Informational)
QA review: Needs Improvement

## Alert
Scheduled AV digest reported detections across three endpoints: PUA:Win32/BundleLoader on MAN-WS-204, Adware:JS/PopServe on LDN-WS-133, and Virus:DOS/EICAR_Test_File on LDN-WS-140. The digest stated all detections were remediated successfully on first action.

## Hypothesis
Malicious/security-event hypothesis: Genuine PUA/adware detections occurred on endpoints and required AV remediation.

Benign hypothesis: Some or all detections were expected/test activity or harmless artifacts, with no actual endpoint compromise.

## Evidence checked
Queried the raw av_events table for all three affected hosts:

av_events
| where data contains "MAN-WS-204"
    or data contains "LDN-WS-133"
    or data contains "LDN-WS-140"
| order by data asc

Raw evidence showed:

MAN-WS-204: BundleLoader detected 2026-10-05 05:31:02Z → quarantine SUCCESS at 05:31:04Z → rescan CLEAN at 07:31:04Z. This corresponds to previously investigated CLD-0202.
LDN-WS-133: PopServe detected in browser cache 2026-10-06 11:02:18Z → quarantine SUCCESS one second later.
LDN-WS-140: EICAR detected 2026-10-09 10:15:30Z, explicitly noted as a security awareness exercise → quarantine SUCCESS one second later.
LDN-WS-133: PopServe appeared again 2026-10-12 06:11:20Z → quarantine SUCCESS one second later.

A separate query of LDN-WS-133 confirmed exactly two PopServe detection/remediation pairs:

av_events
| where data contains "LDN-WS-133"

The raw evidence therefore shows four detection events across three hosts, not three detections as stated in the digest. No failed remediation is present.

## Action
Close as successfully remediated, with monitoring recommended for LDN-WS-133. No escalation required based on available evidence. MAN-WS-204 was quarantined and subsequently rescanned clean. LDN-WS-140 was confirmed as an authorized EICAR awareness test. Both LDN-WS-133 PopServe detections were successfully quarantined on the first attempt. Monitor LDN-WS-133 for further recurrence and investigate the browser/source if PopServe appears again.

## Justification
Raw av_events telemetry was queried for MAN-WS-204, LDN-WS-133, and LDN-WS-140. On 2026-10-05 05:31:02Z, MAN-WS-204 detected PUA:Win32/BundleLoader; quarantine succeeded at 05:31:04Z, followed by a CLEAN rescan at 07:31:04Z. This corresponds to CLD-0202.

On 2026-10-06 11:02:18Z, LDN-WS-133 detected Adware:JS/PopServe in browser cache and successfully quarantined it at 11:02:19Z. The same detection recurred on 2026-10-12 06:11:20Z and was again successfully quarantined on the first attempt at 06:11:21Z. No failed remediation is present.

On 2026-10-09 10:15:30Z, LDN-WS-140 detected Virus:DOS/EICAR_Test_File at C:\Awareness\eicar.txt. The raw record explicitly identifies it as part of the security awareness exercise, and quarantine succeeded at 10:15:31Z.

The raw telemetry therefore verifies genuine PUA/adware detections but also identifies the EICAR event as authorized testing. All four observed detection events were successfully remediated, with MAN-WS-204 additionally confirmed clean on rescan. No evidence currently shows active malware, failed containment, or broader compromise. Verdict: True Positive. Severity: Low.

The digest narrative states there were three detections, but raw telemetry contains four detection events across three endpoints because PopServe was detected twice on LDN-WS-133.

## Tuning note
No suppression recommended for the genuine PUA/adware detections. Consider excluding or separately classifying authorized EICAR security-awareness testing to reduce expected test noise. Preserve visibility on repeated PopServe detections, as recurrence on LDN-WS-133 may warrant investigation if observed again.
